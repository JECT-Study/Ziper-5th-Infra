# 0002 예약 운영과 운영 E2E 증거

- 상태: 채택 — 예약 정책·관측 코드 로컬 검증, 운영 구성과 E2E 미완료
- 날짜: 2026-11-06

## 배경

홈서버의 BIOS 일정은 매일 03:00–06:00 Asia/Seoul 종료다. 시간은 변경될 수 있지만 외부에서 BIOS를 제어하지 않는다. 예상된 종료와 비정상 장애를 구분하고, 홈 배포마다 동일 이미지를 Cloud Run에 반영한다. 운영 장애부터 백업 성공 응답까지 600초를 실제 측정하고 증거는 별도 Infra PR에 남긴다.

## 결정

예약 시간의 출처는 `config/production.json`이며 README와 함께 갱신한다. 구간은 시작 포함·종료 제외이며 자정을 지나는 시간도 지원한다. 예약 구간에는 회로 상태와 독립적으로 백업을 선택한다. 06시 이후에는 기존 회로의 복구 조건을 적용한다. 사용자 요청은 여전히 헬스 표본에 합산하지 않는다. ADR 0001의 FSM은 유지하고 예약 시간의 라우팅만 이 결정으로 보완한다.

배포는 예정 종료 전 30분을 포함한 02:30–06:00 KST에 보류한다. 홈이 준비되지 않은 경우에도 양쪽 운영 반영을 시작하지 않는다. 자동 대기열은 두지 않으며 운영자가 수동 재실행한다. 배포 보류·성공·실패 안내는 기존 Discord 채널의 Incoming Webhook으로 보낸다. 키는 Server 저장소 `production` 환경의 `DISCORD_DEPLOY_WEBHOOK_URL` Secret에 둔다. 알림 실패는 배포 성공과 구분하며 불명확한 전송을 재시도하거나 배포를 다시 실행하지 않는다.

공개 전환 전 현재 파일과 전체 이력을 검사한다. 인프라 본체·설정·재사용 workflow·ADR·E2E 기록은 Infra에, main 수동 진입점과 probe 식별 헤더는 Server에 둔다. 공개 Server의 표준 runner에서 운영 작업을 직렬화하며 검토한 Infra SHA를 고정한다. 이 실행 경로의 전환은 아직 구현 완료가 아니다.

성공한 Server main CI의 artifact로 이미지 하나를 만들고 양쪽을 같은 digest로 배포한다. Cloud Run 후보 검증 후 홈을 갱신하며 양쪽 readiness와 digest 일치를 완료 조건으로 삼는다. 마이그레이션은 전용 단계로 분리하고 런타임 중복 수행을 막는다. GCP는 Singapore, 요청 기반·최소 0·최대 1 인스턴스로 시작하고 월 US$1 목표와 지출 차단을 우선한다. 차단 반영 지연과 Registry·Secret Manager·네트워크 비용 때문에 절대 상한을 보장하지 않는다.

`GET /_ops/circuit`은 별도 32자 이상 토큰으로 인증하고 회로·예약 이유·최근 전이·다음 alarm만 반환한다. 인증 실패는 404이고 상태 변경 기능은 없다. 토큰·Google ID token·계정 키는 응답에 포함하지 않는다. 최근 전이는 SQLite에 최대 100건 저장해 로그 샘플링과 독립적으로 확인한다.

## 대안

- 예정된 종료도 실패율로 판단: 매일 약 6분의 불필요한 요청 실패가 생기므로 제외한다.
- 정해진 06시에 홈으로 강제 복귀: 부팅이 늦으면 사용자 요청을 실패시키므로 제외한다.
- Cloud Run만 새벽에 먼저 배포: 양쪽 릴리스 일치와 수동 운영을 우선해 제외한다.
- GitHub 봇 댓글: 사용자의 선택에 따라 Discord로 대체한다.

## 영향과 한계

시간이 실제 BIOS와 달라지면 필요 없는 백업 사용 또는 일반 회로의 전환 지연이 발생할 수 있다. README·설정 변경 및 운영 반영을 함께 수행해야 한다. 월 예산 차단 중 홈도 꺼져 있으면 503이 발생할 수 있다. Cloud Run 최소 0은 콜드 스타트 증거가 아니며 실제 시작 로그를 확인해야 한다.

통제 실험은 집어 앱과 집어 전용 Tunnel에만 수행하고 타 서비스나 장비 전원을 조작하지 않는다. 먼저 자동 복구 watchdog과 운영 접근을 검증해야 한다. 실제 새벽 한 주기는 외부에서 관찰한다. 600초는 외부 제어기의 장애 명령 전부터 백업 정상 응답 완료까지 측정한다. 실패·미검증을 결과에서 숨기지 않는다. 현재 운영 E2E·watchdog·동일 이미지 배포 경로는 아직 미구현 또는 미실행이며 후속 검증 대상이다.
